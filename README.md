# Road of the Dead — Fan Port

An experimental fan port of **Road of the Dead**, made with the help of ChatGPT and OpenAI Codex using the **Godot Engine**.

This is a fan-made project created for fun and as an experiment. It is **not finished**, and things may be broken, incomplete, or change in future versions. I ran out of my Codex free trial while working on it, so consider this a work in progress rather than a complete release.

## About the Project

The goal of this project was to experiment with recreating and porting *Road of the Dead* in Godot. AI tools helped with parts of the development, but this is still an experimental project and may not perfectly match the original game.

- **Engine:** Godot Engine
- **Type:** Fan port / experimental build
- **Status:** Work in progress
- **Made for:** Fun and learning

## Downloads

- **Godot project/source files:** You're in the right place! Clone or download this GitHub repository to view the project files and open the project in Godot.
- **Playable Windows build:** Get the game `.exe` from the project's **itch.io page**: [Itch game page](https://pazoro.itch.io/road-of-the-dead-fan-port).

## Running the Godot Project

1. Download or clone this repository.
2. Install the Godot version compatible with the project.(4.7.2)
3. Open Godot and import/open the project folder.
4. Run the project from the Godot Editor.

The Windows `.exe` is distributed separately on itch.io; this GitHub repository is for the Godot project files.

## Performance

I made this project with my own low-end PC in mind. Performance depends on your CPU, GPU, and RAM, so RAM alone does not tell the whole story. Your results may vary depending on your hardware.
